Welcome! This portal is hosted on the DMZ web server of the Resilient Enterprise Campus Network, a secure and highly available enterprise network designed and simulated in Cisco Packet Tracer.

About the project

The network is built in a hierarchical model with redundancy at every layer, two internet providers, a firewall-protected DMZ, centrally managed Wi-Fi and VoIP.

Key technologies

  • VLANs 10 (Management), 20 (LAN), 50 (WLAN), 70 (VoIP), 90 (Servers), 199 (Blackhole)
  • HSRP gateway redundancy and PVST root placement
  • OSPF routing on firewalls, routers and multilayer switches
  • LACP EtherChannel between core switches
  • Dual-ISP internet with NAT/PAT on the ASA firewalls
  • DMZ for public servers, with firewall access rules
  • SSH remote management restricted by access list
  • PortFast and BPDU Guard on access ports
